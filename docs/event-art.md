# Tiketko event artwork

The nine category/hero masters in this directory are original synthetic
artwork created specifically for Tiketko. They contain no event logos,
artist likenesses, trademarks, or third-party promotional photography.

`listings/` contains deterministic derivatives generated with:

```bash
npm run art:generate
```

Each active seed listing receives its own crop, palette wash, and visual
signature while remaining visibly category-based. These images are editorial
discovery covers, not official organizer artwork. Organizer-supplied assets
should replace them only after usage rights and durable storage are verified.
